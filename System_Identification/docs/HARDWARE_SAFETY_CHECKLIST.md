# 真机系统辨识安全检查表

> 本文件是以后通电和运动前必须逐项通过的检查表，不代表现在已经允许执行真机操作。

小白判断标准很简单：任何一项不知道、没有验证或和计划不一致，就先不让电机动。

## 1. 已知硬件条件

- 用户确认机器人可以刚性悬空，八条腿完全不接触。
- 用户确认存在实体急停。
- 用户确认当前按 24 V 电机工况准备；正式实验仍需记录当时的真实母线电压。
- 温度、错误码和母线电压的软件读取能力尚未全部确认。

若电机完整型号确为 DM-J8006-2EC V1.1，制造商公开信息为：

- 6:1 减速比；
- 8 N·m 额定转矩；
- 20 N·m 峰值转矩；
- 24–48 V 工作电压；
- CAN 可反馈位置、速度、转矩和电机温度；
- 具有驱动器/电机温度保护。

公开规格只用来提前列检查项目。真正实验时，以机器人铭牌、固件和每台电机实际读到的设置为准。如果仍使用 6S 锂电，24 V 不是恒定实测值，还要记录满电、标称电压和负载压降。

## 2. 任何电机使能前

- [ ] 确认实验授权只覆盖本次明确列出的动作。
- [ ] 工装承载、固定点、螺栓和防摆措施经过人工检查。
- [ ] 所有关节全程不会碰地、碰架、互撞或拉扯线束。
- [ ] 人员退出扫掠空间；无松动物品。
- [ ] 实体急停可触达，并实际测试能切断驱动。
- [ ] 电源具备合适的电流/电压保护和吸收再生能量的能力。
- [ ] 首次运行不使用电池电量过低或未知状态的电源。
- [ ] CAN channel、ID、反馈 ID 唯一且与接线一致。
- [ ] 代码路径确认不会在构造对象时自动使能。
- [ ] 默认行为必须是：遇到未知、超时或异常就不使能，不能“先动起来再看看”。

## 3. 电机不使能，只读取信息

- [ ] 读取每台电机状态码和反馈新鲜度。
- [ ] 读取 `sw_ver, Gr, Damp, Inertia, PMAX, VMAX, TMAX`。
- [ ] 读取 `CTRL_MODE, TIMEOUT` 及可用保护阈值。
- [ ] 保存上位机配置截图/导出文件。
- [ ] 确认温度字段的帧格式；若本地驱动不支持，先补解析并用录制帧离线测试。
- [ ] 确认母线电压来源；无可靠接口时准备独立测量。
- [ ] 比较八台电机参数是否一致，差异必须解释。

## 4. 程序里必须有的保护

- [ ] 连续反馈超时停止；
- [ ] 位置绝对限位；
- [ ] 目标位置相对当前位置限位；
- [ ] 目标变化率限制；
- [ ] 速度限制；
- [ ] 根据 PD 误差估算的力矩限制；
- [ ] 电机错误码立即处理；
- [ ] 温度限制，若温度不可读则限制试验时长并人工冷却检查；
- [ ] 电压/电流异常处理；
- [ ] Ctrl+C、程序异常和日志队列故障均能安全失能；
- [ ] 程序无论正常结束还是报错，最后都能执行失能，不能被第二个异常打断。

所有数值阈值应在仿真预演和用户确认后冻结。不能仅用电机峰值能力当作实验安全阈值。

## 5. 一步一步放开动作

### S0 — 完全不使能

只读寄存器和状态；确认不会自动切换模式或使能。

### S1 — 单关节低增益保持

只激活一个关节，其他关节明确保持失能或经批准的安全状态。验证反馈、符号、急停和软件停止。

### S2 — 单关节小位移

先正负对称、小幅、低频；每次动作前打印并记录最大目标、估算转矩、速度和时长。

### S3 — 单关节低频、小幅扫频

必须先在同一模型、同一 Kp/Kd 和限幅下仿真预演；观察频谱、峰值速度和估算力矩。

### S4 — 八关节悬空

使用对称信号，先缩幅/缩频验证；任何接触、摆动、异常响声、温升或反馈异常立即退出。

### S5 — 最后才做地面验证

只有悬空模型用新动作验证通过后才进行；顺序为站立、踏步、慢速行走，不直接高速部署。

## 6. 立即停止条件

- 实体急停触发或操作员要求停止；
- 任一电机反馈超时或状态码异常；
- 位置、目标变化率、速度、估算转矩、电流、电压或温度超过冻结阈值；
- 机器人或工装出现摆动、松动、碰撞、异响、异味；
- 日志时间戳异常、丢帧严重或控制周期显著失真；
- 实际运动方向与预期不一致；
- 实际 Kp/Kd、模式或限幅与 manifest 不一致。

停止后保留故障前后的原始记录，不立即重复运行；先完成根因分析。
