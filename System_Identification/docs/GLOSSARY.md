# 常用词解释

这里只解释本项目最常见的词。看到英文不用背，知道它在解决什么问题就够了。

| 项目里的词 | 口语解释 | 容易误解的地方 |
|---|---|---|
| System Identification / SysID | 系统辨识：根据真机运动反推仿真参数 | 不是把所有训练参数一起调 |
| Sim-to-Real | 在仿真训练，再放到真机上运行 | 失败不一定都是物理参数不准 |
| control contract | 控制约定：双方用什么命令、单位、频率、增益和限制 | action 一样不代表最终电机命令一样 |
| joint mapping/order | 仿真关节和真实电机怎么一一对应、按什么顺序排列 | 顺序错一个，整条策略都会错 |
| `q_cmd` / `q_des` | 希望关节去的角度 | 要分清策略原始目标和限速后的实际目标 |
| `q_real` | 真机反馈的实际角度 | 可能有零位偏差、量化和延迟 |
| `q_sim` | 仿真中实际到达的角度 | 不是仿真目标角度 |
| `dq` | 关节角速度 | 单位通常是 rad/s，不要和 rpm 混用 |
| `tau` / effort | 关节转矩 | 电机反馈值可能是估算值，不一定是独立传感器真值 |
| Kp | 位置没到目标时，用多大力往目标拉 | 大并不一定好，过大可能振荡或猛动 |
| Kd | 运动时提供多大阻尼 | 和速度反馈噪声、滤波有关 |
| action | 策略输出的数字 | 还要经过缩放、限幅和目标生成才到电机 |
| action scale | 把策略输出换成多大角度或力矩 | 真机再乘一次会破坏训练时的动作含义 |
| clip / limit | 把数值限制在安全或模型允许的范围内 | 训练和真机限制位置不同，效果也不同 |
| `dt` | 仿真物理每一步经过多少秒 | `1/dt` 是物理更新频率 |
| decimation | 做多少次物理步后，策略才更新一次 | 策略频率 = `1 / (dt × decimation)` |
| effort limit | 模型平时允许的转矩上限 | 和峰值转矩、求解器限制可能不是一回事 |
| saturation effort | 电机零速附近的峰值/堵转能力参数 | 不能理解成长期安全使用转矩 |
| armature | 加到关节上的有效折算惯量 | 可能吸收电机、减速器和模型误差，不等于单个零件真值 |
| viscous friction | 速度越快越明显的阻力 | 容易和 Kd 或速度滤波混在一起 |
| Coulomb friction | 运动后大致固定大小的干摩擦 | 不完全等于“静摩擦” |
| Stribeck friction | 专门描述低速起步附近摩擦变化的更复杂模型 | 普通模型确实解释不了时再加 |
| encoder bias | 编码器/关节零位剩余偏差 | 大的零位错误应先人工校准 |
| delay | 延迟 | 必须说清是通信延迟、反馈年龄还是整体响应延迟 |
| jitter | 周期忽快忽慢，也叫抖动 | 平均频率正常也可能抖动很大 |
| raw data | 原始数据 | 只保存，不覆盖、不滤波 |
| processed data | 对齐、清洗或滤波后的数据 | 必须能追溯到原始数据和处理方法 |
| manifest | 一次实验的“身份证” | 记录硬件、代码、参数、动作和安全条件 |
| dry-run | 不依赖真机运动的试跑 | 先确认程序和数据格式能完整跑通 |
| chirp | 从慢到快的扫频摆动 | 频率上限必须由安全和机构能力决定 |
| A/B test | 只改变一个主要条件做对照 | 其他配置和随机种子应尽量一致 |
| blind validation | 用没参与调参的新动作考试 | 不能一边看结果一边继续调通过标准 |
| RMSE | 把整段误差合成一个数，越小通常越好 | 不能代替峰值、相位和逐关节检查 |
| PACE | 用悬空轨迹和大量并行仿真寻找执行器参数的方法 | 示例参数不能直接照抄到 Bennett |
| CMA-ES | 一种自动尝试很多组参数、逐步找更优解的方法 | 参数范围过宽、变量过多会很慢或不可信 |
| Domain Randomization | 训练时让部分参数在范围内变化 | 中心值和范围最好来自实测，不是越大越好 |

专业文件仍会保留标准英文名，方便和代码、论文、Isaac Lab 文档一一对应；第一次出现时尽量同时给中文解释。
