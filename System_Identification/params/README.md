# params — 辨识结果的唯一出口

各工作包得出的参数最终只写在这里（带版本号），Isaac Lab 和 MuJoCo 只从这里读取，不在别处各改各的。

建议文件（有结果才创建，不预先造空文件）：

| 文件 | 来源工作包 | 内容 |
|---|---|---|
| `actuator.yaml` | 05、07 | 电枢惯量、摩擦、延迟、偏置、转矩-转速包络 |
| `timing.yaml` | 02 | 命令/反馈周期、延迟分布、DLL/驱动版本 |
| `rigid_body.yaml` | 00 | 质量、质心、惯量、电池型号 |
| `sensors.yaml` | 08 | IMU 安装旋转、零偏、噪声、编码器噪声 |
| `joint_zero.yaml` | 03 | 8 个关节的零位偏差 δq 与不确定度 |

每个文件必须写明：生成日期、来源实验的 run_id、使用的电池、DLL profile、置信度（高/中/低）、有效范围。
