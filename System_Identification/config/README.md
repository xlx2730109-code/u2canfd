# 配置目录

这里保存电脑能够直接读取的实验设置，让同一次实验以后还能照样重做。这里不保存密码、密钥或随手试的一次性命令。

计划中的配置类型：

- `robot.yaml`：八个关节分别对应哪台电机、方向、零位、机械范围和电机设置；
- `control_contract.yaml`：仿真、策略和真机各自怎么收发命令，包括频率、PD、动作、观测和限幅；
- `sysid.yaml`：准备寻找哪些参数、允许它们在哪个范围变化、怎么判断好坏；
- `experiment_*.yaml`：某一次具体实验的全部设置。

目前只有 `experiment_template.yaml`。其中 `TBD` 表示“必须补上”，`unknown` 表示“现在确实不知道”。正式实验前必须逐项处理，不能直接把模板拿去运行。
