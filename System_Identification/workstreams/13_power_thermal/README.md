# 13 — 电源与温度

电池电压会随电量和负载变化（现有 4000 mAh 与 5300 mAh 两块 6S 电池换着用），电机温度会影响摩擦、转矩常数和保护动作。仿真里这些都是常数，真机不是。

要得到：

1. 空载、典型负载、峰值负载下的母线电压，以及两块电池的差异（质量、质心、压降）；
2. 电机/驱动温度随运行时间的变化，和 `OT_Value`（过温阈值）、`OC_Value`（过流保护，含义待查）的关系；
3. 热降额和低电压对转矩-转速包络的影响（与第 05 包的曲线模型配合）；
4. 每次实验必须记录用的是哪块电池、起始电压、结束电压和最高温度。

电压/温度在电机反馈帧里是否提供，待第 01 包确认；不提供时需要独立采集（电源、BMS 或万用表记录）。
