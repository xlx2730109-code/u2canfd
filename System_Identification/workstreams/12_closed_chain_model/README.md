# 12 — 闭链模型一致性（Bennett 空间闭环）

Bennett 腿是空间过约束闭链，URDF 是树形结构，USD / MuJoCo 里要重新加闭环约束和主从动关系。这里检查"仿真里的闭链"和"实物闭链"是不是同一个机构。

要回答的问题：

1. URDF、USD、MuJoCo 三个模型的主动关节、从动关节、闭环约束是否一致？
2. 闭环几何误差 e_g（开题报告式 6-6）在整个工作空间里有多大？约束求解的软硬程度（Isaac Lab / MuJoCo 不同）会不会让足端轨迹偏离？
3. 实物的装配误差、间隙让真实闭链与名义参数（a=180 mm，α=β=45°，σ=145°）差多少？足端实测轨迹能否反推出有效杆长/扭角？
4. 同一条关节指令，三种引擎里足端轨迹差多少？

输入：SW 装配体（API 只读）、URDF/USD/MuJoCo 模型、第 03 包的关节映射。
输出：足端轨迹对比、闭环误差统计、需要修改的模型参数建议。
不直接覆盖训练在用的模型。
