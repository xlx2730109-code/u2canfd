# 05 — 达妙 DM-J8006 24 V 官方曲线模型

这里集中保存达妙厂家曲线、从图片读出的数据、按转速限制最大转矩的代码、生成图和相关训练对比。

## 内容

- `source_snapshot/assets_motor/`：从训练项目复制的电机模型原样备份，这里不改；
- `related_experiments/trot_motor_ab_snapshot/`：相关 Trot 对比任务、分析脚本和已有结果备份；
- [PROVENANCE.md](PROVENANCE.md)：说明这些文件从哪里来、复制时是什么版本；
- [SHA256SUMS.txt](SHA256SUMS.txt)：用来证明复制后的文件没有悄悄变化；
- [ASSESSMENT.md](ASSESSMENT.md)：这个模型能表示什么、缺什么、以后怎么公平比较。

## 当前结论

它是比单一直线 `DCMotor` 更有厂家依据的 **24 V 转矩—转速上限候选**：转得越快时，电机还能给多少转矩。它可能让高速区更接近厂家曲线，但不是完整真实电机模型。

不能因为“来自官方曲线”就自动替换所有训练任务。公平做法是保持任务、奖励、随机种子和其他电机参数不变，只更换被比较的电机模型：

1. 原标准 `DCMotor`；
2. 相同标称参数的标准 `DCMotor`；
3. 真正使用 `DamiaoMotorCfg`、按曲线查表的模型；
4. 在上一步基础上，再加入实测有效惯量、摩擦、偏差和延迟的模型。

最终看它在新动作和真机上的误差是否更小，不能只看一次训练的总 reward。
