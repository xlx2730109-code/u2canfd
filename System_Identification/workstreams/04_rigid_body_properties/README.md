# 04 — 尺寸、质量、质心和惯量

这里负责机器人"骨架和重量"的参数，不和电机的有效折算惯量混在一起。

## 约束（2026-10-08）
- 腿已装好，不能拆；没有备件可单独称重；有秤，能悬吊整机。
- 两块电池换着用（4000 mAh / 5300 mAh），质量和质心都随电池变化。
- SW 模型（`E:\HuanCun\Desktop\sw_work\Bennett\Bennett\Bennett_test5.SLDASM`）整机质量 12.0098 kg，URDF 约 11.90 kg，两者差 0.11 kg 未解释。

## 做法（整机法，由简到繁）
1. 整机称重（分别用两块电池），与 SW 和 URDF 比。
2. 去掉电池称一次，得到电池质量，与 SW 里的电池质量比。
3. 质心：悬吊法或多点称重，得到水平位置和高度，与 SW 比。
4. 惯量：整机扭摆/双线摆（绕竖直轴最容易），其余轴视条件。
5. 从 SW 用 API 只读列出每个零件的材料、密度和是否有质量覆盖，找出可疑项（3D 打印件按实心算会偏大，线缆螺丝未建模会偏小）。
6. 电机、电池、控制板用官方质量核对 SW 里对应零件。
7. 汇总三方对齐表：SW、URDF/USD、实测；差异大于阈值时给出修改建议，不直接覆盖训练在用模型。

## 规则
- 每个数字写清坐标系、单位、包含哪些零件、对应哪个机器人版本和哪块电池。
- SW 只用 API 读，不保存、不改模型。
- 结果写入 `../../params/rigid_body.yaml`（有结论后）。
