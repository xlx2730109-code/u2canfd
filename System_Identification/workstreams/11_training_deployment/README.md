# 11 — 接入训练、部署和真机验收

只有 07 的新动作考试通过后，才把新模型接进 Bennett 专用的独立训练任务。原来的共享任务和基线继续保留，方便公平对比和退回。

训练奖励、PPO 参数和网络结构属于“怎么训练”，不是系统辨识结果。选模型不能只看总 reward，还要看是否稳定、动作是否经常撞限幅、落足冲击、功率、速度跟踪，以及真机和仿真的真实差距。

真机按单关节、八关节悬空、站立、踏步、慢速行走逐级放行，不直接跳到高速走路。

修改正式训练配置或让真机运动，都需要你在当次任务里明确同意。


## 可选：脚垫摩擦
足端没有传感器也不影响：脚垫摩擦系数可用斜面法（放在地面材料上慢慢抬高，测滑动角，μ=tanθ）粗测。现有训练的摩擦随机化范围是 0.6–1.3，若实测落在范围内就不需要单独做。原来的 09 号接触工作包并入这里。
