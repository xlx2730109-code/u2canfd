# 03 — 关节零位标定

关节顺序、正方向和映射在之前的 sim2real 里已经验证过，这里不再单独做（只有一处符号表冲突，见 `../../docs/CONTROL_CONTRACT.md`，改代码即可）。

**这里只解决零位问题**：SW 里只是用约束给了关节角度，样机上设置零位时靠肉眼判断是否在零位，所以真机的"0 rad"和仿真的"0 rad"可能差几度。策略输出的是"相对默认姿态的位置偏移"，零位错 1–5° 就会让观测和目标整体偏移，足端位置误差可到厘米级，站立时还会产生稳态力矩。

## 怎么标（按推荐顺序）
1. **定位工装**：打印一个能把腿卡在 SW 零位姿态的定位块/销，卡住后读编码器，得到真机零位偏差。最准、最可重复。
2. **倾角仪法**：腿悬空静止，用数显倾角仪贴在连杆上，测连杆的世界角度，与 SW 里该关节角下的连杆角度比。不需要拆东西。
3. **机械极限法**：在机构的硬限位（或奇异位形）处读编码器，与 SW 中同一位置的关节角比。
4. **交叉检验**：PACE 式悬空辨识里的"位置偏置"项（06 工作包），以及四脚着地时足端应等高的约束；这两种会和重力、摩擦耦合，只作交叉验证，不作主标定。

## 做法与输出
- 每个主动关节（8 个）得到一个零位偏差 δq（rad），带重复测量的离散度。
- 偏差写入 `../../params/joint_zero.yaml`，部署时读取，不要靠重新设置电机零位寄存器（避免每次手动判断）。
- 之后在仿真里把 δq 作为"关节位置偏置"随机化的中心值，范围取实测离散度。
- 零位可能随拆装、松动漂移，每次大改动后复查。

## 完成标准
- 8 个关节的 δq 和不确定度；
- 同一姿态下真机读数与 SW 值的对比图；
- 改完后再测一次，残差小于 0.5°（暂定）。
