# 00 — 模型链校核：SW → URDF → USD

这是整个系统辨识的第一步：先确认仿真里的"机器人"和 SolidWorks 里的机器人是同一个，再去和真机比。链条是：

```text
SW 装配体 (Bennett_test5.SLDASM) ──► URDF ──► USD (Isaac Lab) ──► MuJoCo
        第 1 关              第 2 关        第 3 关         第 4 关
```

## 每一关查什么

| 关 | 比什么 | 怎么读 |
|---|---|---|
| 1. SW 本身 | 材料/密度、是否有手动质量覆盖、整机与分件质量、质心、惯量；电机/电池/控制板与官方质量核对 | SolidWorks COM API 只读，不保存、不改模型 |
| 2. SW → URDF | 每个 link 的质量、质心、惯量张量、坐标系、关节原点和方向、关节限位 | 解析 URDF（XML），与第 1 关逐 link 对表 |
| 3. URDF → USD | USD 里每个刚体的 mass/CoM/inertia 是否被引擎重算或覆盖；闭环关节、主从动关系、关节方向、碰撞体 | 用 pxr/Isaac Lab 读 USD，或 `print_scene` 类脚本 |
| 4. USD → MuJoCo | 同一套质量惯量与关节映射 | 读 MJCF，对表 |

## 产出

- 逐 link 对表（SW / URDF / USD / MuJoCo 的质量、质心、惯量），差异超阈值的标红；
- 整机总质量、质心、惯量的四方对比；
- 需要修改的项目清单（只提建议，不直接覆盖训练在用的模型）；
- 之后真机实测（第 04 包）的结果回到这里，作为第 5 栏"实测"。

## 与其他工作包的分工

- 本包只做"模型之间"的对齐，不碰真机。
- `04_rigid_body_properties` 做真机实测（称重、悬吊、扭摆）。
- `12_closed_chain_model` 专门检查闭链几何和约束（足端轨迹层面）。

规则：SW 只用 API 只读；每个数字写清坐标系、单位、版本和电池型号。
