# 08 — 检查编码器和 IMU

这里负责确认传感器“读出来的数到底代表什么”：单位、正方向、比例、固定偏差、最小分辨率、噪声、更新快慢、滤波和时间对齐。

旧 IMU 数据里的 projected gravity 是由姿态角算出来的重力方向，不能再用同一套姿态公式证明自己正确。以后必须保存原始加速度、角速度、设备时间和电脑接收时间，并用独立的摆放方向或已知运动来验证。

复杂的 IMU 噪声模型可以后做，但安装方向、坐标轴、单位和数据格式要在进入策略真机闭环前查清。

## 2026-09-17 静态水平度实测（调平前 / 调平后）

数据（纯串口读取 IMU，全程不动电机）：
- 调平前：`data/raw/2026-09-16/20260916_234406_imu_static_r01/`（6 s）
- 调平后：`data/raw/2026-09-17/20260917_010126_imu_static_r01/`（10 s）

| 指标 | 调平前 | 调平后 |
|---|---|---|
| roll | −1.02° | **+0.70°** |
| pitch | −0.44° | **+0.09°** |
| **合倾角** | **1.13°** | **0.72°** |
| 倾角波动 σ | 0.19° | 0.15° |
| 重力模长 \|g\| | 9.808 m/s² | 9.806 m/s² |
| 陀螺零偏 | ≤0.0007 °/s | ≤0.0012 °/s |
| yaw（自报） | 27.3° | 100.9° |

解读：
- 合倾角 **1.13° → 0.72°**（降 36%）。pitch 从 −0.44° 调到 +0.09°（基本平了），roll 从 −1.02° 调到 +0.70°。
- 波动 σ 只有 0.15~0.19°：读数稳，倾角是机身真实的静态姿态，不是"抖出来的均值"。
- 过程是把机身垫平后反复微调、每次复测；读数会跟着每次调整变，说明测的是真倾角而不是死数。
- 剩下的 0.72° 几乎全在 roll 方向（+y 侧高 0.70°，机身宽 20 cm 时约合 2.4 mm），已在手调精度以下，不再继续拧；仿真里按固定偏置扣掉即可。
- "IMU 装歪"和"机身真歪"在数学上不可分（绕竖直轴转机身不改变重力在机身系里的方向；两次采集 yaw 27°→101° 而倾角与 yaw 无关），要分离只能拿外部水平仪（手机水平仪贴同一条基准面）跟 IMU 读数比。

轴向与单位（已用 IMU 自报欧拉角交叉验证，差 <0.05°）：
- reg1 = 加速度 m/s²；reg2 = 角速度 °/s；reg3 = 欧拉角 deg（yaw 两次采集不同：27.3° → 100.9°，说明调平过程中机身被转过）
- `roll = atan2(ay, az)`，`pitch = atan2(−ax, √(ay²+az²))`，`倾角 = acos(az/|g|)`

结论（答辩口径）：
- IMU 数据质量很好：静态波动 0.15~0.19°，陀螺零偏 ~0.001 °/s，可以直接进仿真；
- 静态水平度：调平前合倾角 1.13°，调平后 **0.72°**（roll +0.70°、pitch +0.09°）；
- 残余 0.72° 已在手调精度以下，仿真里直接当固定偏置建进去即可，不影响使用。
