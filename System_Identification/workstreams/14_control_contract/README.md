# 00 — 对齐真机和仿真的控制方式

说白了，这里要确认真机和仿真是不是“用同一种语言”。这里不负责找摩擦或惯量。

要核对：

- 八个关节叫什么、按什么顺序排列；
- 策略输出什么，经过缩放和限幅后最终发给电机什么；
- 角度、速度、力矩使用什么单位；
- 默认姿态、Kp/Kd 和命令保持方式；
- 仿真物理频率、策略频率和真机发命令频率；
- 位置、速度和力矩分别在哪里受限。

完成后应得到：

- `control_contract.yaml`：电脑能读取的统一控制说明；
- 训练配置与真机代码的逐项差异表；
- 自动检查脚本，发现顺序、维度或关键参数不一致就报错。

当前候选基线是：200 Hz 仿真物理更新、50 Hz 策略、1000 Hz 真机命令循环、Kp=28、Kd=2、8 N·m 常用模型限矩、20 N·m 零速峰值能力。它们只是从某个 Trot1 产物和部署代码读取的快照，还没有定成所有实验统一值。
