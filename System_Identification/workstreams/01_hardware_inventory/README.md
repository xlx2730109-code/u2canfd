# 01 — 查清真实硬件和固件

说白了，这里负责回答“手上这台机器人现在到底是什么状态”。网上的产品参数只能参考，不能替代实机读取。

要记录：

- 八台电机的完整型号、序列号、CAN 通道和 ID；
- 固件版本、减速比、驱动器里的阻尼/惯量设置、最大位置/速度/转矩；
- 当前控制模式、通信超时和保护阈值；
- 电池/BMS、悬挂架和实体急停；
- 能否读取错误码、温度和母线电压。

完成后应得到设备清单、不使能电机的寄存器快照、达妙上位机截图或导出文件，以及八台电机之间的差异表。

当前已确认：机器人可以刚性悬空，八条腿完全不接触，并有实体急停；用户确认按 24 V 电机工况准备。固件和每台电机的实际设置仍待检查。
